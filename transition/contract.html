Appendix B.2. AFW 360 transition: the contract

Frozen at gate G1 · shared codes, paths, headers, interfaces and expected counts

Published

September 21, 2026

The contract is what lets many agents build files and code at the same time without seeing each other’s output. It fixes every code, path, header, interface and expected count that they must agree on in advance.

This document is the readable reference. The contract itself is the set of machine-readable files in contract/. Each package card repeats the rules its package needs, so agents do not read this document unless a card says so.

1 What the contract is

Changing it. label_triage.csv, codes.csv, legacy_overrides.csv, legacy_national_columns.csv, tab_plan.csv and expected_counts.csv are edited by WP99 only, and only to apply the user’s answers at gate G0. The contract is frozen at gate G1. After that, an agent that finds a contract error stops and reports it; it does not work around the error by inventing its own convention. A change then needs the user, a new plan commit and a rerun of check_contract.R.

Rscript .docs/transition/contract/check_contract.R --root .

2 Codes

2.1 Rules for codes

  • A code matches ^[A-Z][A-Z0-9_]{0,31}$.
  • _T (total) and _Z (not applicable) are reserved sentinels. They never appear in a codelist, and no code starts with them. GEO and URBANISATION are never _Z.
  • A category code is <var_code>_<category>. Its variable is looked up through the var_code column, never by parsing the prefix (gap t).
  • TBD is a reserved token for a required value that cannot be known from the inputs. It is allowed only in a column that has no codelist, and only on a DRAFT row. The validator warns on it there, and gives an error once the row is no longer DRAFT (gap d).
  • Everything the transition creates is status = DRAFT, with version_added = 0.1.0.

2.2 The three share codes (D4)

A population share is never a new indicator. It is one of three codes, chosen by what the breakdown counts:

POP_SH has one ref_period, which is INTERVIEW. A recall period such as “employed in the last 12 months” belongs to the universe of the breakdown variable, not to the indicator (gap z).

2.3 Series IDs

series_id is the indicator, then each qualifier code in ascending qualifier slot_order, then the defining breakdown category, all joined by .. Examples are POV_HC.POVLINE_PL300.PPP_2021, CONS_SH.COICOP_CP01.ACQ_PURCH, POP_HH_SH.HE_COUNT_0 and HE_AGE. It is an identifier, not a code, so the 32-character limit does not apply to it. Its characters are A–Z, 0–9, _ and ..

2.4 Geography

  • ADM0 codes (SN, GW) are geometry-only. They are registered in CL_GEO but never used in the GEO column of a data row, where the whole country is _T (gap k).
  • SN01 and SN13 are invalid as delivered. They are repaired with sf::st_make_valid() under sf_use_s2(FALSE), from the plain (non-_em) shapefiles (gap u).
  • Three zone names come from headers truncated at 32 characters. Their full names are TBD inside name_en until a producer confirms them (gap v).
  • Zones and agro-ecological zones have no geometry.

3 Formats

3.1 CSV files (gap r)

Every CSV that the pipeline writes:

  • is UTF-8 without a byte-order mark, with LF line endings and one header row;
  • has exactly the columns of csv_headers.csv, in that order;
  • writes a missing value as an empty string, never NA;
  • writes numbers in fixed notation, with at most 10 decimals and trailing zeros trimmed, never in scientific notation;
  • separates multi-valued fields with one space, and has no line break inside a cell.

Readers read every column as character, strip a BOM and accept CRLF. .gitattributes keeps these files LF on checkout.

Data-file rows are sorted by the 18 key columns, as strings in C-locale order. Two runs of the converter with the same --timestamp are byte-identical.

3.2 The 18 key columns

DATAFLOW, REF_AREA, GEO, TIME_PERIOD, INDICATOR, SEX, AGE, URBANISATION, COMP_BREAKDOWN_1…5, MEASURE_QUAL_1…5 are the first 18 of the 26 columns. The remaining 8 (OBS_VALUE to OBS_COMMENT) are never part of the key.

3.3 Field grammars

  • CL_INDICATOR.qualifiers is _Z when the indicator takes no qualifier. Otherwise it holds VAR:CODE,CODE entries, separated by one space, in qualifier slot_order. VAR:* allows every category.
  • CL_INDICATOR.checks holds tokens separated by one space, from the vocabulary in Section 4.4.
  • LEGACY_LABELS.assert_rule is EQUALS:<series_id> or ONE_MINUS:<series_id>, optionally followed by tol=<number>. The default tolerance is 0. duplicate_of holds the same target series_id. In the triage seed these point at row IDs such as L008; WP09 translates them.
  • LEGACY_LABELS.sheet is a sheet name, or * for National, ADM 1 and ZAE.
  • In LEGACY_OVERRIDES, sheet, column and legacy_label accept * for “every”. WITHHOLD wins over COMMENT.
  • Registry paths are relative: GEO_SOURCES.file to geo/boundaries/, FIGURES.file to assets/figures/, and TEXT.file to content/text/.

4 Interfaces

4.1 Command lines

Every script takes --root <repo root> (default .) and is run from the repo root. Every generator also takes --out-root <dir> (default: the root). It reads inputs under the root and writes outputs under the out-root at the same relative paths, so any output can be rebuilt into a temporary directory and compared.

4.2 Shared R modules

4.3 Validator modules

Each pipeline/R/validate_<module>.R defines functions named vc_<module>_<check>(ctx). Each returns a tibble with the columns check_id, severity, file, row_key, message, where zero rows means pass. validate.R discovers them with ls(pattern = "^vc_"). check_id is <MODULE>.<NAME>, and severity is ERROR, WARN or INFO. 4.4 Checks vocabulary and tolerances (gap h)

The tokens are RANGE_0_1, RANGE_NONNEG, AGG_SUM, AGG_BRACKET, AGG_NPOP_MEAN, SUM_TO_1_OVER:<QUAL_VAR>, SUM_TO_1_OVER_BRK, EQUALS_NPOP_RATIO, MONOTONE_IN:POVLINE and NONE.

  • The parent of a row is the row of the same series in the cut TOTAL. Provenance (series_id, cut_id) comes from required_rows().
  • For ROUNDED_2DP files, h = 0.005 × scale:
    • a sum of k children against its parent tolerates (k + 1) × h;
    • a closure over k categories tolerates k × h (for COICOP, ±0.065);
    • a bracket tolerates h on each side;
    • monotonicity gets no tolerance.
  • Every comparison is abs(deviation) <= tolerance + 1e-9.
  • AGG_BRACKET (the parent lies within [min child − h, max child + h]) stands in for AGG_NPOP_MEAN while N_POP is absent. The two N_POP rules are skipped with an INFO finding on legacy files.
  • A group with a withheld or empty child is skipped with a WARN. A closure over a partial category set is skipped with an INFO.

These rules were run against the raw workbooks with these tolerances, and the legacy data break none of them.

5 Expected counts

contract/expected_counts.csv holds every target: source cells per sheet, labels, series, indicator codes, data rows by status, withheld cells, poverty counts, rows of every metadata file, features per boundary layer, and the 122 legacy files. Acceptance scripts read their targets from it by check_id, and none is hard-coded. check_contract.R recomputes 51 of them from the seeds and the workbooks. WP17 checks all of them on the finished repository.

6 Out of scope

This transition does not:

  • switch the dashboard to the new files (objective 3 of CLAUDE.md);
  • produce any non-legacy data: every row is a legacy conversion, with precision = ROUNDED_2DP and status = DRAFT;
  • populate N_OBS, N_POP, STD_ERR or the confidence intervals;
  • build content/SLOTS.csv or resolve {…} references in prose (gap p and open decision 10).
