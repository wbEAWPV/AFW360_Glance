# WP00 — Setup and environment check

- **Wave:** 0. **Depends on:** nothing. **Slug:** `setup`.
- **Verification:** none. This package creates a branch and a tag and proves that the tools work. It has no verifier and no acceptance script.

## Goal

Create the integration branch and the fixed reference tag, and prove that every tool the later packages need runs on this machine, before any tokens are spent on real work.

## Read (exactly this)

`packages/COMMON.md` and this card.

## Owned outputs

- The branch `transition/main` and the tag `transition-base`, both at the current `dev/eb` commit.
- `.docs/transition/reports/WP00-implementer.md`, committed on `transition/main`.

## Steps

1. Confirm the start state. `git rev-parse dev/eb` succeeds, and `git ls-tree -r dev/eb --name-only` lists `.docs/transition/packages/COMMON.md`, `.docs/transition/contract/codes.csv` and `.gitattributes`. If one of them is missing, stop and report `BLOCKED`: the plan is not committed on `dev/eb`. Then look at `git branch --list transition/main` and `git tag --list transition-base`:
   - neither exists: this is a first run; go on with step 2;
   - both exist, and every subject of `git log --format=%s transition-base..transition/main` starts with `WP00:`: this is a retry after a failed environment check. Skip step 2, run `git switch transition/main`, and go on with step 3;
   - anything else: stop and report `BLOCKED`, because the transition has already started.
2. In your worktree, run `git switch -c transition/main dev/eb`, then `git tag transition-base`.
3. Run `git config core.longpaths true`.
4. Run each environment check below, and record the command, the exit code and the last lines of output:
   1. `Rscript --version`.
   2. Every R package of `COMMON.md` section 5 loads: `Rscript -e 'p <- c("readxl","dplyr","tidyr","readr","stringr","purrr","sf","digest","testthat","checkmate","cli","jsonlite"); print(sapply(p, requireNamespace, quietly=TRUE))'`. All must be `TRUE`.
   3. `Rscript .docs/transition/contract/check_contract.R --root . 2>&1 | tail -n 8`. It must end with "All contract checks passed."
   4. The dashboard renders: `env -u QUARTO_R QUARTO_PYTHON="C:/WBG/Python313/python.exe" quarto render index.qmd 2>&1 | tail -n 15`. Success means `_site/index.html` was rewritten and the output has no "Error" or "Traceback". Do not read the HTML.
   5. `git check-attr eol -- metadata/x.csv` prints `eol: lf`, and `git check-attr text -- data_raw/x.txt` prints `text: unset`.
5. Write the report (`COMMON.md` section 8; list the five checks under "Checks"). Commit only the report (`git add .docs/transition/reports/WP00-implementer.md`, not `git add -A`) on `transition/main` with the subject `WP00: implement - STATUS: DONE`, or `WP00: implement - STATUS: BLOCKED` if a check of step 4 failed. A retry overwrites the report and adds a new commit. Then run `git switch --detach`.

If any check of step 4 fails, still commit the report. Your final message is `STATUS: BLOCKED` with the failing command and its message. Do not try to repair the environment. After the user has repaired it, the orchestrator launches this card again, and step 1 treats that run as a retry.

## Out of scope

Everything else. Do not edit `STATUS.md`; the wave-1 integrator marks WP00.
