# WP15 — Legacy converter

- **Wave:** 3. **Depends on:** wave 2 merged. **Slug:** `converter`. **Acceptance script:** `pipeline/acceptance/wp15_converter.R`.

## Goal

Turn the two legacy workbooks into the two data files and their manifests, driven entirely by metadata. The converter holds no label, no column name and no country-specific rule of its own. A label that is edited in a workbook must make the converter stop; it must never make a row vanish silently.

## Read (exactly this)

- `packages/COMMON.md` and this card.
- The function signatures in `pipeline/R/io.R`, `codes.R` and `constants.R`. Use `grep -n "function("`.
- Through R: `head()` of `LEGACY_LABELS`, `LEGACY_COLUMNS`, `LEGACY_OVERRIDES`, `SERIES_PLAN` and `SURVEYS`. For the dimensions, `nrow()` of each.
- Through R, `names()` and `head(3)` of `CL_INDICATOR` (you need `stat_unit`), `CL_BRK_VAR` and `CL_QUAL_VAR` (`slot_order`), and `CL_COMP_BREAKDOWN` and `CL_QUALIFIER` (`var_code`).
- Do **not** read `pipeline/R/reconcile.R`, or anything else of WP16. The two packages are built independently on purpose.

## Rules you need

**Command line.** `Rscript pipeline/convert_legacy.R --root . --country SEN|GNB|ALL [--timestamp <ISO 8601>] [--out-root <dir>]`. The countries are the distinct `ref_area` values of `LEGACY_COLUMNS`. A country's workbook is `data_raw/tables/Tables_<ref_area>.xlsx`.

**One row for each mapped cell.** For each country, each `LEGACY_COLUMNS` row with `action = MAP`, and each `LEGACY_LABELS` row with `action = MAP` that applies to the column's sheet (`sheet` equal to it, or `*` for `National`, `ADM 1` and `ZAE`):

- The series comes from `SERIES_PLAN`, through `series_id`. It gives `INDICATOR`, the qualifiers (`MEASURE_QUALS`) and the defining breakdown.
- The cell comes from the `LEGACY_COLUMNS` row: `GEO`, `URBANISATION` and `COMP_BREAKDOWN`. An empty one means `_T`.
- `DATAFLOW = AFW360_HH`, and `REF_AREA` is the country.
- `TIME_PERIOD` and the manifest's `survey_id` come from the country's row in `SURVEYS.csv`. Stop if there is not exactly one such row.
- `SEX` and `AGE` are `_T` when the indicator's `CL_INDICATOR.stat_unit` is `IND`, and `_Z` otherwise.
- The breakdown slots hold the column's `COMP_BREAKDOWN` (if there is one) plus the series' defining breakdown (if there is one), ordered with `slot_sort()` by `CL_BRK_VAR.slot_order`, which is found through `CL_COMP_BREAKDOWN.var_code`, and padded to five with `_T`. The qualifier slots are ordered the same way by `CL_QUAL_VAR.slot_order`, found through `CL_QUALIFIER.var_code`, and padded with `_Z`.
- The qualifier slots hold the series' qualifiers, ordered by `CL_QUAL_VAR.slot_order` and padded to five with `_Z`.
- `OBS_VALUE = round(as.numeric(raw) * scale, 10)`, with `scale` from `LEGACY_LABELS`, written through `fmt_num()`. `OBS_STATUS = A`.
- An empty cell gives an empty `OBS_VALUE`, `OBS_STATUS = O`, and `OBS_COMMENT = "LEGACY_EMPTY: empty cell in sheet '<sheet>', column '<column>'"` (decision D9).
- `STD_ERR`, `CI_LOWER`, `CI_UPPER`, `N_OBS` and `N_POP` stay empty, because the workbooks do not have them.

**Overrides** (`LEGACY_OVERRIDES`; `*` matches every value, and sheet `*` means the three sheets):

- `WITHHOLD`: the cell produces no row.
- `COMMENT`: the row is kept and `obs_comment` is written to `OBS_COMMENT`. On an empty cell it is appended after the `LEGACY_EMPTY:` text, separated by ` | `.
- When both actions match a cell, `WITHHOLD` wins.

**Nothing is dropped silently.** The converter stops with a clear message when:

- a workbook label has no `LEGACY_LABELS` row for its sheet, or a workbook column has no `LEGACY_COLUMNS` row;
- a `LEGACY_LABELS` or `LEGACY_COLUMNS` row matches nothing in the workbook;
- a `DUPLICATE_OF` or `DERIVED` label breaks its `assert_rule` in any cell. `EQUALS:<series_id>` means the cell equals the cell of the `MAP` label with that `series_id`; `ONE_MINUS:<series_id>` means it equals 1 minus that cell. The optional ` tol=<x>` defaults to 0, and the comparison is `abs(deviation) <= tol + 1e-9`. Cells where either side is empty are skipped. These labels produce no rows.

`SKIP` labels and `SKIP` columns (the whole `Departement` sheet) produce no rows.

**Output.** Sort the rows by the 18 key columns, as plain strings in C-locale order (`method = "radix"`), and write with `write_std_csv()` to `data/AFW360_HH_<ref_area>_<TIME_PERIOD>.csv`. The key must be unique; stop if it is not.

**Manifest** (`<stem>_manifest.csv`, with the columns `key, value` and these 16 keys in this order):

| Key | Value |
|---|---|
| `dataflow` | `AFW360_HH` |
| `dsd_version`, `metadata_version` | The content of `metadata/VERSION` |
| `ref_area`, `time_period` | The country, and the year from `SURVEYS.csv` |
| `source_type` | `SURVEY` |
| `survey_id` | From `SURVEYS.csv` |
| `precision` | `ROUNDED_2DP` |
| `file_name`, `n_rows` | The data file's base name and its row count |
| `producer` | `AFW DIP/POV team` |
| `program` | `pipeline/convert_legacy.R` |
| `software` | `R <major>.<minor>` |
| `run_timestamp` | The `--timestamp` value, or the current UTC time |
| `status` | `DRAFT` |
| `notes` | `Legacy conversion of data_raw/tables/Tables_<ref_area>.xlsx` |

Commit the data files produced with `--timestamp 2026-01-01T00:00:00Z`.

## Steps

1. Write `convert_tables.R` (pure functions: read a workbook, expand its cells, apply the overrides, assert the rules, build the rows), `manifest.R` and the CLI.
2. Write the tests. Build a tiny workbook with `writexl` if it is installed; otherwise test the pure functions on small data frames. Cover the slot order, the `_Z` rule, an empty cell, `WITHHOLD`, `COMMENT`, a failing assertion, and an unknown label.
3. Run `--country ALL --timestamp 2026-01-01T00:00:00Z`. Compare the row counts with `expected_counts.csv` (`DATA.SEN.ROWS`, `DATA.SEN.ROWS.A`, `GNB.DATA.ROWS`, `GNB.DATA.ROWS.A`, `GNB.DATA.ROWS.O`), and commit.

## Acceptance checks

- WP15.A1: both data files have the header of `metadata/structure/DSD_AFW360_HH.csv` (`id`, in order).
- WP15.A2: SEN has `DATA.SEN.ROWS` rows, all with `OBS_STATUS = A`.
- WP15.A3: GNB has `GNB.DATA.ROWS` rows, of which `GNB.DATA.ROWS.A` are `A` and `GNB.DATA.ROWS.O` are `O`.
- WP15.A4: the 18-column key is unique in both files, and no key cell is empty.
- WP15.A5: for every `A` row, the value divided by the series' `scale` equals the source cell within `1e-9`. The acceptance script traces every row back through the three legacy files, not a sample.
- WP15.A6: every `O` row has a comment that starts with `LEGACY_EMPTY:`. No withheld cell has a row: the acceptance script rebuilds the withheld keys itself from `LEGACY_OVERRIDES`, `LEGACY_LABELS` and `LEGACY_COLUMNS`; it does not just count rows. Every cell that a `COMMENT` override matches carries its `obs_comment`.
- WP15.A7: `SEX` and `AGE` are `_Z` exactly when the indicator's `stat_unit` is not `IND`, and `_T` otherwise.
- WP15.A8: each manifest has the 16 keys in order, with `precision = ROUNDED_2DP` and `status = DRAFT`. Its `n_rows` equals the file, and its `survey_id`, `ref_area` and `time_period` match `SURVEYS.csv`.
- WP15.A9: two runs with `--timestamp 2026-01-01T00:00:00Z --out-root <tempdir>` are byte-identical to each other and to the four committed files (two data files and two manifests).
- WP15.A10: the outputs contain no `e+`, no `e-`, no cell equal to `NA`, no BOM and no CR byte (check the blobs).
- WP15.A11: in `pipeline/convert_legacy.R` and `pipeline/R/convert_tables.R`, `grep` finds no `estimate`, no legacy label text, no sheet name (`National`, `ADM 1`, `ZAE`, `Departement`), and no country code outside the usage message. The check looks at code only: lines that start with `#` are removed before the search. The string `*` for the wildcard is allowed, and so is a documented constant that expands the sheet wildcard from the distinct `sheet` values of `LEGACY_COLUMNS` with `action = MAP`.
- WP15.A12: in a temporary copy where one `LEGACY_LABELS.legacy_label` has been altered, the converter exits non-zero and names the unmapped label.

## Verifier focus

Trace 30 random source cells (both countries, all three sheets) to their output rows by hand, from the raw workbook. Check the national poverty counts against `POVNUM.*` in `expected_counts.csv`: they are stored in persons, for example 6520000.
