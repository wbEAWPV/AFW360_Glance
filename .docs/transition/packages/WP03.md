# WP03 — Pipeline scaffold

- **Wave:** 1. **Depends on:** WP00. **Slug:** `scaffold`. **Acceptance script:** `pipeline/acceptance/wp03_scaffold.R`.

## Goal

The shared R library, constants, DSD file, test helpers and acceptance runner that every later package builds on. Later packages call these functions by name, so the names and signatures below are fixed.

## Read (exactly this)

`packages/COMMON.md`, this card, and the data-file rows of `contract/csv_headers.csv` (`file == "AFW360_HH_<ISO3>_<YEAR>.csv"`, 26 rows; print `position`, `column` and `status` only).

## Owned outputs

`pipeline/README.md`, `pipeline/R/io.R`, `pipeline/R/constants.R`, `pipeline/R/codes.R`, `pipeline/R/ctx.R`, `pipeline/acceptance/run_all.R`, `pipeline/tests/testthat.R`, `pipeline/tests/testthat/helper-temp-root.R`, `pipeline/tests/testthat/test-io.R`, `pipeline/tests/testthat/test-codes.R`, `pipeline/tests/testthat/test-ctx.R`, `metadata/VERSION`, `metadata/CHANGELOG.md`, `metadata/structure/DSD_AFW360_HH.csv`, `metadata/structure/COLUMNS.csv`.

## Interfaces (exact names and signatures)

**`pipeline/R/io.R`**

- `read_std_csv(path)`: a tibble with every column as character. It strips a BOM, accepts CRLF, and keeps an empty cell as `""`, never `NA`.
- `write_std_csv(df, path)`: follows `COMMON.md` section 3. `NA` becomes `""`, numeric columns go through `fmt_num()`, and parent directories are created. It writes bytes that do not depend on the platform (LF on Windows too).
- `fmt_num(x)`: fixed notation, at most 10 decimals, trailing zeros and a trailing `.` trimmed, `NA` to `""`. It never returns scientific notation.
- `sha256_file(path)`: lower-case hex, through digest.
- `load_metadata(root)`: a named list of tibbles, one per `*.csv` found recursively under `<root>/metadata` and `<root>/content`, keyed by file stem (`meta$CL_GEO`, `meta$SERIES_PLAN`, `meta$TEXT`). A folder that does not exist is skipped silently.
- `repo_path(root, ...)`: `file.path` under the root.
- `cli_arg(args, flag, default = NULL)`: the value after `flag` in `commandArgs(trailingOnly = TRUE)`, or the default. `cli_args(args, flag)`: every value that follows a repeatable flag. `cli_flag(args, flag)`: `TRUE` if the flag is present.

**`pipeline/R/constants.R`**

`DATAFLOW_ID = "AFW360_HH"`, `SENTINEL_TOTAL = "_T"`, `SENTINEL_NA = "_Z"`, `TBD = "TBD"`, `DSD_COLUMNS` (the 26 names, in order) and `KEY_COLUMNS` (the first 18 of them: `DATAFLOW` to `MEASURE_QUAL_5`).

**`pipeline/R/codes.R`**

- `is_valid_code(x)`: a logical vector. `TRUE` when `x` matches `^[A-Z][A-Z0-9_]{0,31}$` and does not start with `_T` or `_Z`.
- `slot_sort(codes, var_of, slot_order_of)`: `codes` is a character vector of category codes, `var_of` a named character vector (category to `var_code`), and `slot_order_of` a named vector (`var_code` to `slot_order`, coerced to integer). It returns the codes ordered by `slot_order`, with ties broken by `var_code`. It stops with an error on a code that `var_of` does not know.
- `fill_slots(codes, n = 5, pad)`: the codes followed by `pad`, to length `n`. It stops when there are more than `n` codes.

**`pipeline/R/ctx.R`**

`build_ctx(root, data_files = character(0), opts = list())` returns the list every validator check receives:

- `root`;
- `meta`, which is `load_metadata(root)`;
- `data`, a named list of tibbles from `read_std_csv`, keyed by file base name;
- `manifests`, a named list with the same keys, each a named character vector (key to value) read from `<stem>_manifest.csv` beside the data file, or an empty vector when the manifest is missing;
- `precision`, a named character vector taken from each manifest's `precision`, with `EXACT` as the default;
- `opts`.

**`pipeline/tests/testthat/helper-temp-root.R`**

- `make_temp_root(root, include = c("metadata", "content", "geo", "assets", "data"))`: copies the folders that exist into a fresh temporary directory and returns its path.
- `edit_csv(path, fn)`: reads with `read_std_csv`, applies `fn` to the tibble, and writes it back with `write_std_csv`.
- `find_root()`: the repo root, found by walking up from the working directory to the folder that holds `pipeline/`.

Every test file begins by sourcing the modules it needs from `file.path(find_root(), "pipeline", "R")`.

## Steps

1. Implement the modules above, with roxygen-style comments on each function.
2. Write `metadata/structure/DSD_AFW360_HH.csv` with 26 rows and the columns `position, id, role, codelist, required, sentinel, description`.
   - `id` and `required` come from `csv_headers.csv` (`column` and `status`).
   - `role`: `constant` for `DATAFLOW`; `breakdown` for `REF_AREA`, `GEO`, `SEX`, `AGE`, `URBANISATION` and `COMP_BREAKDOWN_1…5`; `reference` for `TIME_PERIOD`; `qualifier` for `INDICATOR` and `MEASURE_QUAL_1…5`; `measure` for `OBS_VALUE`; `attribute` for the last 7.
   - `codelist`: `CL_AREA`, `CL_GEO`, `CL_INDICATOR`, `CL_SEX`, `CL_AGE`, `CL_URBANISATION`, `CL_COMP_BREAKDOWN` (5 slots), `CL_QUALIFIER` (5 slots) and `CL_OBS_STATUS`; empty elsewhere.
   - `sentinel`: `_T` for `GEO`, `URBANISATION` and the breakdown slots; `_T _Z` for `SEX` and `AGE`; `_Z` for the qualifier slots; empty elsewhere.
3. Write `metadata/structure/COLUMNS.csv`, the machine-readable column registry of every metadata and content file (gap aa). The validator reads it to know which columns a file must have and which are required. Generate it from `contract/csv_headers.csv` with a few lines of R: keep the columns `file, position, column, status, description`; drop the rows of the data file, the manifest and the validator findings; keep the row order. Do not retype it.
4. Write `metadata/VERSION` (the single line `0.1.0`) and `metadata/CHANGELOG.md` (a title and the heading `## 0.1.0 (unreleased)`).
5. Write `pipeline/acceptance/run_all.R`. It runs every `pipeline/acceptance/wp*.R` in name order as `Rscript <script> --root <root>`, prints each script's `CHECK` lines, then prints one summary line per script. It exits 0 only if every script exits 0, and also exits 0 when there are no scripts.
6. Write `pipeline/tests/testthat.R`, which runs `testthat::test_dir("pipeline/tests/testthat")` from the repo root. Write unit tests that cover every function above.
7. Write `pipeline/README.md`: the layout, how to run each entry point, and the conventions of `COMMON.md` sections 3 to 5. Say that `bootstrap/` holds one-time generators that are frozen after metadata 0.1.0 (decision D11).

## Acceptance checks

- WP03.A1: `Rscript -e "testthat::test_dir('pipeline/tests/testthat', stop_on_failure = TRUE)"` exits 0.
- WP03.A2: the DSD has 26 rows, and its `id` column equals the data-file columns of `csv_headers.csv`, in the same order. `DSD_COLUMNS` equals it too, and `KEY_COLUMNS` is its first 18.
- WP03.A3: `fmt_num(c(0.37, 6520000, -3460.12, 1e-7, 100, NA))` gives `"0.37" "6520000" "-3460.12" "0.0000001" "100" ""`.
- WP03.A4: a `write_std_csv` output file has no BOM and no CR byte, and `NA` is written as empty.
- WP03.A5: `read_std_csv` on a file with a BOM, CRLF and an empty cell returns all-character columns, a clean first header, and `""` for the empty cell.
- WP03.A6: `is_valid_code` accepts `SN01` and `POV_HC`; it rejects `_T`, `_ZX`, `pov_hc`, `1A` and a 33-character code.
- WP03.A7: `slot_sort(c("HE_COUNT_0","QUINT_Q1"), c(HE_COUNT_0="HE_COUNT", QUINT_Q1="QUINT"), c(HE_COUNT="50", QUINT="10"))` returns `QUINT_Q1` first. `fill_slots("A", 3, "_T")` returns `A _T _T`.
- WP03.A8: in a temporary copy, `run_all.R` exits 0 with no scripts, and exits non-zero when a dummy failing script is present.
- WP03.A9: `metadata/VERSION` is exactly `0.1.0`. `build_ctx(root)` returns a list with the six names above, even when no data file is given.
- WP03.A10: `COLUMNS.csv` equals `csv_headers.csv` without the rows of the data file, the manifest and the validator findings (28 files remain, `COLUMNS.csv` itself among them), with the same column order within each file.

## Verifier focus

Call every function by its contract name from a fresh R session that sources only the module files. A wrong name or argument order breaks six later packages, so it is a failure even when the unit tests pass.
