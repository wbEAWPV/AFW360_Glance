- **Wave:** 2. **Depends on:** wave 1 merged, and gate G1. **Slug:** `content`. **Acceptance script:** `pipeline/acceptance/wp10_content.R`.

## Goal

Move the dashboard's prose, its one figure and the survey descriptions into the standard's files.

## Read (exactly this)

- `packages/COMMON.md` and this card.
- `data_raw/text/About_SEN.txt`, `Messages_SEN.txt` and `Messages_GNB.txt`. They are small. `About.txt` is a byte-identical copy of `About_SEN.txt`, and `About_GNB.txt` holds only the word `TEXT`.
- In `index.qmd`, only the two key-message blocks: run `grep -n "Row Messages" index.qmd`, and read 18 lines from each hit.
- `data_raw/figures/Fiscal Equity SEN.png`. Look at it once, to describe it.
- The header rows of `TEXT.csv`, `FIGURES.csv` and `SURVEYS.csv` in `contract/csv_headers.csv`.

Your prompt carries the line `MESSAGES_SOURCE: dashboard` or `MESSAGES_SOURCE: files`, which is the user's answer T1 at gate G0. The default is `dashboard`.

## Rules you need

- Each `TEXT.csv` row has exactly one of `body` and `file`. `body` is a single paragraph with no line breaks. Anything longer goes in a Markdown file under `content/text/`, and `file` holds its path relative to `content/text/`.
- Markdown is limited to paragraphs, emphasis, links, lists and footnotes. There is no raw HTML, and no chunk syntax (`{python}`, `#|`, `Markdown(`).
- Prose is stored literally. Keep the `##` number placeholders as they are. Invent no numbers, and write no new prose.
- An unknown required text is `TBD`.
- `status = DRAFT` on every row. `updated_on = 2026-09-21`, the date the legacy text was frozen; keep it as a constant in the script.
- `About.txt` is treated as Senegal-specific. There is no `ref_area = ALL` row (gap x).
- The figure is copied byte for byte. Its registry row carries the sha256.

## Acceptance checks

- WP10.A1: `TEXT.csv` has `META.TEXT` rows with the (`slot`, `ref_area`, `order`) keys of the table above. Each row has exactly one of `body` and `file`, and the referenced file exists.
- WP10.A2: no `TEXT.csv` body or title, and no `.md` file, contains `<`, `{python}`, `Markdown(` or `#|`. No body contains a line break.
- WP10.A3: after whitespace normalization, `about.md` equals the text of `data_raw/text/About_SEN.txt`.
- WP10.A4: after whitespace normalization, the three Senegal bodies equal the source named by `MESSAGES_SOURCE`, with wrappers stripped. The `##` placeholders survive. The three Guinea-Bissau titles equal the titles of the same source (`dashboard`: the second `## Row Messages` block of `index.qmd`; `files`: `Messages_GNB.txt`).
- WP10.A5: the PNG's sha256 equals that of `data_raw/figures/Fiscal Equity SEN.png`. `FIGURES.csv` holds that sha256, and `alt_text_en` is longer than 40 characters.
- WP10.A6: `SURVEYS.csv` has `META.SURVEYS` rows. The SEN row contains `7100`, `519.8`, `2021-11`, `2022-09`, `ANSD` and `XOF`. Both rows have `time_period = 2021` and `status = DRAFT`.
- WP10.A7: the headers of the three CSV files equal `csv_headers.csv`. Every **R** column is filled, with `TBD` allowed.
- WP10.A8: both scripts with `--out-root <tempdir>` reproduce every output byte for byte. The unit tests pass.
