# WP01 — Move legacy inputs to `data_raw/`

- **Wave:** 1. **Depends on:** WP00. **Slug:** `data-raw`. **Acceptance script:** `pipeline/acceptance/wp01_data-raw.R`.

## Goal

Put all 122 legacy files in one byte-frozen folder, without changing what the dashboard shows (decision D2).

## Read (exactly this)

`packages/COMMON.md`, this card, and `CLAUDE.md`. Do not read `index.qmd` whole (1,195 lines); use `grep -n "INPUT " index.qmd`. Do not read any rendered HTML.

## Inputs

`INPUT Tables/`, `INPUT shp/`, `INPUT Text/`, `INPUT Figures/`, `dsf.qqqww`, `map_test.png`, `index.qmd`. List them with `git ls-files 'INPUT Tables' 'INPUT shp' 'INPUT Text' 'INPUT Figures' dsf.qqqww map_test.png` (122 paths).

## Owned outputs

- `data_raw/**`, including `data_raw/README.md` and `data_raw/CHECKSUMS.sha256`.
- The 12 path strings in `index.qmd`.
- `CLAUDE.md`, and a one-line note at the top of `.docs/input-tables-findings.md`.
- The removal, by `git mv`, of `INPUT Tables/**`, `INPUT shp/**`, `INPUT Text/**`, `INPUT Figures/**`, `dsf.qqqww` and `map_test.png`.

## Steps

1. **Baseline.** Before changing anything, render the dashboard (`COMMON.md` section 6) and copy `_site/index.html` to a temporary directory outside the repo. If the render fails, stop and report `BLOCKED`. Do not fix the dashboard.
2. **Move with `git mv`,** keeping file names:

   | From | To |
   |---|---|
   | `INPUT Tables/Tables_SEN.xlsx`, `Tables_GNB.xlsx` | `data_raw/tables/` |
   | `INPUT Tables/Tables_SEN_TEST.xlsx` | `data_raw/scratch/` |
   | `INPUT shp/*` (110 files) | `data_raw/shp/` |
   | `INPUT Text/About.txt`, `About_SEN.txt`, `About_GNB.txt`, `Messages_SEN.txt`, `Messages_GNB.txt` | `data_raw/text/` |
   | `INPUT Text/Messages_SEN.txt2` | `data_raw/scratch/` |
   | `INPUT Figures/Fiscal Equity SEN.png` | `data_raw/figures/` |
   | `dsf.qqqww`, `map_test.png` | `data_raw/scratch/` |

3. **Restore the exact bytes.** `.gitattributes` marks `data_raw/**` as binary, but the moved text files still have the CRLF line endings of their old checkout. Run `git checkout -- data_raw`, so that every working file equals its blob. Afterwards `git status --porcelain data_raw` shows only renames (`R`), and nothing modified.
4. **Write `data_raw/CHECKSUMS.sha256`** in `sha256sum` format (`<hash>  <path>`, paths relative to the repo root, sorted by path, 122 lines, LF). Compute each hash from the blob: `git cat-file blob :<path> | sha256sum`.
5. **Write `data_raw/README.md`:** what each subfolder holds; that the files are kept exactly as received and are never edited; that nothing reads `scratch/`; how to verify them (`sha256sum -c data_raw/CHECKSUMS.sha256` from the repo root).
6. **Replace the 12 path references in `index.qmd`**, on lines 188, 370, 371, 658, 665, 675, 694, 1115, 1122, 1132, 1151 and 1182. Nothing else in the file may change.

   | Old text | New text | Lines |
   |---|---|---|
   | `INPUT Tables/` | `data_raw/tables/` | 188, 694, 1151 |
   | `"INPUT Tables" / ` | `"data_raw" / "tables" / ` | 370 |
   | `"INPUT shp" / ` | `"data_raw" / "shp" / ` | 371 |
   | `INPUT Figures/` | `data_raw/figures/` | 658, 665, 1115, 1122 |
   | `INPUT Text/` | `data_raw/text/` | 675, 1132, 1182 |

7. **Update `CLAUDE.md`:**
   - the layout section, with the new paths;
   - the working rule: the inputs now live in byte-frozen `data_raw/`, moved by decision D2, and are still not edited;
   - path mentions in the known issues;
   - a pointer to `.docs/transition/plan.qmd`.
8. **Add one line** at the top of `.docs/input-tables-findings.md`: its paths refer to the original locations, which are now under `data_raw/`.
9. **Render again.** Write a small script (R or Python, in a temporary directory, not committed) that loads both HTML files, replaces the old path strings with the new ones in the baseline (raw, and URL-encoded as `INPUT%20Tables` and so on), and prints only: whether the tag-stripped text is equal, the two `<img>` counts, and the first 3 differing text fragments if there are any.

## Acceptance checks

- WP01.A1: exactly 122 tracked files under `data_raw/`, not counting `README.md` and `CHECKSUMS.sha256`.
- WP01.A2: for every moved file, the blob ID at `transition-base:<old path>` equals the blob ID at `HEAD:<new path>`.
- WP01.A3: `CHECKSUMS.sha256` has 122 lines, and each hash equals both the sha256 of the blob and the sha256 of the working-tree file.
- WP01.A4: no tracked path starts with `INPUT `, and `git grep -n "INPUT " -- . ':!.docs'` finds nothing.
- WP01.A5: `git diff --numstat transition-base HEAD -- index.qmd` shows 12 lines added and 12 removed, and every added line contains `data_raw`.
- WP01.A6: the dashboard render exits 0 and rewrites `_site/index.html` with no "Traceback" in the output.
- WP01.A7: `CLAUDE.md` names `data_raw/` and no longer names `INPUT Tables/`.

The implementer also reports the step-9 comparison in its report. That check needs the baseline render, so it is not part of the acceptance script.

## Verifier focus

Recompute A2 and A3 yourself. Open one moved workbook with readxl and one moved shapefile with sf, to confirm that they still read. Render the dashboard once for A6, and do not read the HTML.
