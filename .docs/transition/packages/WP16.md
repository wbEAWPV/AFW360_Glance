# WP16 — Independent reconciliation tool

- **Wave:** 3, at the same time as WP15. **Depends on:** wave 2 merged. **Slug:** `reconcile`. **Acceptance script:** `pipeline/acceptance/wp16_reconcile.R`.

## Goal

A second, independent path from the data files back to the workbooks. It proves that every source cell is accounted for exactly once, and that every converted value matches its cell. Because it shares no code with the converter, a converter bug cannot hide in it.

## Read (exactly this)

- `packages/COMMON.md` and this card.
- The function signatures in `pipeline/R/io.R`, `codes.R` and `constants.R`, and in the two test helpers. Use `grep -n "function("`.
- Through R: `head()` and `nrow()` of `LEGACY_LABELS`, `LEGACY_COLUMNS`, `LEGACY_OVERRIDES`, `SERIES_PLAN` and `SURVEYS`.
- Through R, `names()` and `head(3)` of `CL_INDICATOR` (`stat_unit`), `CL_BRK_VAR` and `CL_QUAL_VAR` (`slot_order`), and `CL_COMP_BREAKDOWN` and `CL_QUALIFIER` (`var_code`).
- Do **not** read `pipeline/convert_legacy.R`, `pipeline/R/convert_tables.R`, `pipeline/R/manifest.R` or their tests. They may not exist on your branch. If they do, leave them closed. Do not call `required_rows()` either; build your keys from the legacy maps.

## Inputs

`data_raw/tables/*.xlsx`, `metadata/**` and `data/AFW360_HH_*.csv`. The real data files do not exist on your branch, because the converter is being written at the same time. Develop and test on a data file that you generate, as in step 2.

## Rules you need

**Every source cell has exactly one class.** A source cell is (country, sheet, label, column), for every sheet that a workbook has, found with `readxl::excel_sheets()`. The SEN workbook has a `Departement` sheet, and the GNB workbook has none.

| Class | When |
|---|---|
| `skipped` | The column's `LEGACY_COLUMNS.action` is `SKIP` (the whole `Departement` sheet), or the label's `LEGACY_LABELS.action` is `SKIP` |
| `duplicate` | The label's action is `DUPLICATE_OF` |
| `derived` | The label's action is `DERIVED` |
| `withheld` | The label's action is `MAP`, and a `LEGACY_OVERRIDES` row with `action = WITHHOLD` matches the cell (`*` matches everything, and sheet `*` means `National`, `ADM 1` and `ZAE`) |
| `converted` | The label's action is `MAP`, and the cell is not withheld |

**The expected row of a converted cell.** Its 18-column key is built as follows:

- `DATAFLOW = AFW360_HH`, and `REF_AREA` is the country.
- `GEO`, `URBANISATION` and one breakdown category come from the `LEGACY_COLUMNS` row. An empty one means `_T`.
- `TIME_PERIOD` comes from the country's `SURVEYS.csv` row.
- `INDICATOR`, the qualifiers and the defining breakdown come from `SERIES_PLAN`, through the label's `series_id`.
- `SEX` and `AGE` are `_Z` unless the indicator's `stat_unit` is `IND`, in which case they are `_T`.
- The breakdown slots are ordered by `CL_BRK_VAR.slot_order`, found through `CL_COMP_BREAKDOWN.var_code`, and padded with `_T`.
- The qualifier slots are ordered by `CL_QUAL_VAR.slot_order` and padded with `_Z`.

Its expected value is the raw cell times `LEGACY_LABELS.scale`. An empty cell expects `OBS_STATUS = O`, an empty value, and a comment that starts with `LEGACY_EMPTY:`.

**Comparison.** For a converted cell, the data row must exist exactly once, and `round(OBS_VALUE / scale, 2)` must equal `round(raw cell, 2)`. This holds because every legacy cell has at most two decimals (the file's precision is `ROUNDED_2DP`); the rule must be revisited for a source with more decimals. For a converted cell with an empty raw value, the row's `OBS_COMMENT` must start with `LEGACY_EMPTY:`; for a cell that a `COMMENT` override matches, `OBS_COMMENT` must equal the override's `obs_comment`. A wrong comment is a `MISMATCH`. The results are:

- `OK`;
- `MISMATCH`: a different value or status;
- `MISSING_ROW`: no data row for the cell;
- `DUPLICATE_ROW`: more than one data row for the cell;
- `WITHHELD_PRESENT`: a withheld cell has a data row;
- `ORPHAN`: a data row that no source cell explains.

For `duplicate` and `derived` cells, also evaluate the label's `assert_rule` (`EQUALS:<series_id>` or `ONE_MINUS:<series_id>`, with an optional ` tol=<x>`, compared as `abs(deviation) <= tol + 1e-9`). A failure is an `ASSERT_FAIL`.

**Command line.** `Rscript pipeline/reconcile.R --root . --out <report.md> [--csv <cells.csv>]`

- It reconciles every country in `LEGACY_COLUMNS`.
- The Markdown report gives, per country and sheet, the count of each class, the count of each result, the first 10 problems of each kind, and a last line `RECONCILIATION: PASS` or `RECONCILIATION: FAIL`.
- The CSV has one row per source cell, with the columns `ref_area, sheet, legacy_label, column, class, result, source_value, data_value, row_key`.
- It exits 0 only when every result is `OK`, there is no `ORPHAN`, and the class counts per country add up to the number of source cells. It exits 1 otherwise. It exits 2 when a data file is missing.

## Steps

1. Write `pipeline/R/reconcile.R` with three pure functions: `source_cells(root)` (every cell with its class), `expected_rows(root)` (key and expected value for the converted cells), and `reconcile(root)` (the comparison). Then write the CLI.
2. Write the tests: `tmp <- make_temp_root(root)`, write data files into `tmp/data/` from `expected_rows()` itself, check for `PASS`, and then mutate one thing per test. This tests the comparison. The verifier tests `expected_rows()` against the raw workbook.
3. Run it on a temporary root that holds data files generated from `expected_rows()`. Compare the class counts with `expected_counts.csv`:
   - SEN: `DATA.SEN.ROWS` converted, 198 not converted on the three sheets, and `DEPARTEMENT.SKIPPED` skipped;
   - GNB: `GNB.DATA.ROWS` converted and `GNB.WITHHELD_CELLS` withheld.

## Acceptance checks

- WP16.A1: on data files that are consistent with the source, the tool exits 0. Per country, the class counts sum to the source cells (`CELLS.*` in `expected_counts.csv`): SEN 3201 plus 1148 for `Departement`, and GNB 2522.
- WP16.A2: converted cells number `DATA.SEN.ROWS` for SEN and `GNB.DATA.ROWS` for GNB, and withheld cells number `GNB.WITHHELD_CELLS`. `duplicate` plus `derived` plus label-`skipped` cells on the three sheets number 198 for SEN and 156 for GNB.
- WP16.A3: each mutation below gives exit 1 and the named result in the report:
  - a changed value gives `MISMATCH`;
  - a deleted row gives `MISSING_ROW`;
  - a duplicated row gives `DUPLICATE_ROW`;
  - a row added for a withheld cell gives `WITHHELD_PRESENT`;
  - a row with an unplanned key gives `ORPHAN`;
  - an `O` row given a value gives `MISMATCH`.
- WP16.A4: the CSV has the 9 columns above, and one row per source cell.
- WP16.A5: neither the code nor its `git log` refers to `convert_tables`, `convert_legacy` or `required_rows`. The unit tests pass.

## Verifier focus

For 20 random converted cells from both countries and all three sheets, build the expected key by hand from the raw workbook and the legacy maps, and compare it with `expected_rows()`. Confirm the tool's independence from the converter's code (A5).
