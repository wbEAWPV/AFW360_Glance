# WP09 — Legacy maps

- **Wave:** 2. **Depends on:** wave 1 merged, and gate G1. **Slug:** `legacy-maps`. **Acceptance script:** `pipeline/acceptance/wp09_legacy-maps.R`.

## Goal

The three files that tell the converter how every legacy label, column and defective cell maps to the standard. The converter holds no label and no column name of its own; all of them live here.

## Read (exactly this)

- `packages/COMMON.md` and this card.
- `contract/legacy_national_columns.csv` (13 rows) and `contract/legacy_overrides.csv` (12 rows), whole.
- From `contract/label_triage.csv`, about 10 rows of the columns `row_id`, `sheet`, `action`, `series_id`, `duplicate_of`, `scale` and `assert_rule`, plus the 6 rows with `sheet == "*"` whose action is not `MAP`. The script reads the rest.
- From `contract/geo_codes.csv`, the columns `code`, `ref_area`, `scheme`, `legacy_sheet` and `legacy_column`.
- The header rows of `LEGACY_LABELS.csv`, `LEGACY_COLUMNS.csv` and `LEGACY_OVERRIDES.csv` in `contract/csv_headers.csv`.

## Inputs

`data_raw/tables/Tables_SEN.xlsx` (sheets `National`, `ADM 1`, `ZAE`, `Departement`) and `data_raw/tables/Tables_GNB.xlsx` (`National`, `ADM 1`, `ZAE`).

## Rules you need

- Label actions:
  - `MAP`: the label is converted to the series in `series_id`.
  - `DUPLICATE_OF`: it repeats another label and is not converted.
  - `DERIVED`: it can be computed from another label and is not converted.
  - `SKIP`: it is ignored.

  All 82 `Departement` labels are `SKIP` (decision D3).
- `sheet = *` means the three sheets `National`, `ADM 1` and `ZAE`. The sheet name `ADM 1` has a space.
- In the triage, `duplicate_of` and `assert_rule` point at triage row IDs (`L008`). In `LEGACY_LABELS.csv` they point at the target's **`series_id`**: `duplicate_of = CONS_SH.COICOP_CP01`, and `assert_rule = EQUALS:CONS_SH.COICOP_CP01` or `ONE_MINUS:POP_HH_SH.HE_COUNT_0`, with ` tol=0.02` kept where the triage has it. The default tolerance is 0.
- `scale` is a plain decimal: `1` or `1000000`, never `1e+06`. It is empty on rows that are not `MAP`.
- Override actions:
  - `WITHHOLD`: the cell produces no row in the data file (decision D5).
  - `COMMENT`: the value is kept and `OBS_COMMENT` is set.

  `*` in `sheet`, `column` or `legacy_label` means "every". When both actions match a cell, `WITHHOLD` wins.
- Every tolerance comparison is `abs(deviation) <= tol + 1e-9`.

## Steps

Write `build_legacy_maps.R` (`--root`, `--out-root`). It reads the seeds and both workbooks, and writes three files.

1. **`LEGACY_LABELS.csv`**: one row for each triage row, in triage order.
   - `legacy_label`, `sheet`, `action`, `series_id` and `scale` come from the triage.
   - `duplicate_of` and `assert_rule` have their row IDs replaced by the target's `series_id`.
   - `notes` is the triage's `hard_case` and `notes`, joined by `: `.
   - The script checks every `assert_rule` on the raw cells of both countries (the three sheets, every column), and stops if one fails. It appends ` max deviation <x>` to the `notes` of that row.
2. **`LEGACY_COLUMNS.csv`**: one row for every data column of every sheet of both workbooks, read from the workbooks. The order is SEN before GNB; `National`, `ADM 1`, `ZAE`, `Departement`; then workbook column order. Fix the sheet order in the code: `readxl::excel_sheets()` returns the GNB sheets as `National`, `ZAE`, `ADM 1`.
   - `National` columns take `cut_id`, `URBANISATION` and `COMP_BREAKDOWN` from `legacy_national_columns.csv`, and `action = MAP`.
   - `ADM 1` and `ZAE` columns take `GEO` from `geo_codes.csv` (matched on `ref_area`, `legacy_sheet` and `legacy_column`, byte for byte). `cut_id` is `ADM1` for `ADM 1` columns, and the scheme (`ZONES` or `AEZ`) for `ZAE` columns. `action = MAP`.
   - `Departement` columns have `action = SKIP` and every mapping column empty.
   - The script stops if a workbook column has no seed row, or a seed row has no workbook column.
3. **`LEGACY_OVERRIDES.csv`**: one row for each seed row, in seed order.
   - `ref_area`, `sheet`, `column`, `legacy_label`, `action` and `reason` come from the seed.
   - `obs_comment` is `LEGACY_SUSPECT: ` followed by the reason on `COMMENT` rows, and empty on `WITHHOLD` rows.
   - `evidence` is computed from the workbooks:
     - for a single cell, `raw value <v>`;
     - for the `estimateCapital` column, `equal to ZAE estimateZonas_Costeiras_do_Sul on <n> of <N> labels`;
     - for a whole label, `National estimateTotal = <v>; range over all cells <min> to <max>`.
   - The script stops if a row matches no cell.

Then run it, check the results against the counts below, and commit.

## Acceptance checks

- WP09.A1: every (sheet, label) pair of both workbooks matches exactly one `LEGACY_LABELS` row, byte for byte. A `*` row stands for the three sheets. The file has `META.LEGACY_LABELS` rows.
- WP09.A2: every (ref_area, sheet, column) of both workbooks matches exactly one `LEGACY_COLUMNS` row (`META.LEGACY_COLUMNS` rows). Every `GEO` equals `geo_codes.csv`, and `estimateSAB` maps to `GW08`. Every `URBANISATION` and `COMP_BREAKDOWN` equals `legacy_national_columns.csv`.
- WP09.A3: the `MAP` rows' `series_id` set equals the triage's, and `scale` equals the triage's as a number. No cell of the file contains `e+`.
- WP09.A4: every `duplicate_of` and every `assert_rule` target is the `series_id` of a `MAP` row. Every rule holds on the raw data of both countries within its tolerance.
- WP09.A5: `LEGACY_OVERRIDES` has `META.LEGACY_OVERRIDES` rows that equal the seed. Its `WITHHOLD` rows cover exactly `GNB.WITHHELD_CELLS` cells of MAP labels, and every row targets a cell that exists.
- WP09.A6: applying the three files to the raw workbooks gives these counts:
  - SEN: `DATA.SEN.ROWS` rows, all non-empty;
  - GNB: `GNB.DATA.ROWS` rows, of which `GNB.DATA.ROWS.A` are non-empty and `GNB.DATA.ROWS.O` are empty.
- WP09.A7: the headers equal `csv_headers.csv`, and `--out-root <tempdir>` reproduces the three files byte for byte.
